# RAN Technologies website

Official public website for RAN Technologies LLC: <https://ran-technologies.com/>

## Structure

- `index.html` — public homepage
- `relational-origin.html` — intentionally unindexed conceptual page
- `assets/css/site.css` — homepage styles
- `assets/js/site.js` — navigation, demo, and lightbox behavior
- `assets/images/` — reusable site images
- `robots.txt` and `sitemap.xml` — search-engine discovery files

The public site intentionally excludes unpublished implementation mechanics, patent-sensitive material, and claim-relevant technical detail.
